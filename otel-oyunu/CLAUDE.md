## İş dağıtımı (alt ajanlar, `.claude/agents/` repo kökünde)
Ana oturum işi türüne göre devreder; commit, push ve artifact yayını her zaman ana oturumda kalır:
- **hizli-duzelt** (Sonnet): tek hata, küçük özellik/buton, denge sayısı, metin/arayüz düzeltmesi.
- **derin-analiz** (Opus): "baştan analiz et", eksik/hata listesi, mega güncelleme planı, zor hata kök nedeni, performans ölçümü.
- **test-kosucu** (Haiku): test seti, t_sim simülasyonu, dayanıklılık testi; kod değiştirmez, sonucu özetler.
Ana oturumun kendi modeli değişmez (/model ile elle). Büyük güncellemede önerilen: /model → opusplan (plan Opus, uygulama Sonnet).

## Komutlar
- `python3 build.py` → `src/game.html` (sürüm) + `dist/game.html` + `dist/game-offline.html` (three.js gömülü, internetsiz) + `test2.html` (mock THREE) + `chk.js`; sonra `node --check chk.js`.
- Ana döngü `guard()` ile alt sistem başına korunur (p8 frame); hatalar `window.__gameErrs`'te. Misafir döngüsünde bozuk misafir çıkarılır.
- `python3 build.py --bot` bot.js ekler (t_sim için). Testler: `python3 t_boot.py`, t_hire, t_new, t_admin, t_x, t_f, t_staff, t_staff3, t_tech2, t_idle (hepsi argümansız çalışır; MG6+: t_city6, t_ops2, t_world, t_mg7, t_mg8, t_day, t_text, t_next, t_gfx5, t_loda, t_curve, t_saga, t_thief); `python3 t_sim.py 25` denge simülasyonu (bot optimal oynar; şu an 3★~6, 4★~10, 5★~13; 5★ sonrası para prestij projelerine gider; ün ~85 civarında dalgalanır — insan oyuncu daha yavaş). Dayanıklılık: bot 40 gün, varlık/fx sayıları sabit kalmalı. mock testlerinde "ERR_TUNNEL_CONNECTION_FAILED" CDN hatası normaldir.
- Gerçek WebGL görsel: bir kez `git clone --depth 1 --filter=blob:none --sparse -b r128 https://github.com/mrdoob/three.js t3 && git -C t3 sparse-checkout set examples/js`; sonra `python3 mkvis.py && python3 t_vis.py 'wait:3000' 'shot:x.png'` (VW/VH env ile boyut).
